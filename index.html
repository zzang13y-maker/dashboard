Trend Reversal 세부 구성

지표현재값환산점수가중치기여점

SPY·QQQ 각각 환산 후 평균. MA5/20: 종가가 이평선 이상이면 100, 미만이면 0. RSI: 5거래일 변화 -5~+5점 → 0~100. VIX: 5거래일 변화 +10%~−10% → 0~100. 하이일드 OAS: 5관측일 변화 +25~−25bp → 0~100. 변화 없음은 50점. 누락 지표 제외 후 유효 가중치로 재환산하며 60% 미만이면 판단 보류. 80% 미만은 잠정 판단.

보조지표 직접 입력 (선택)

미입력 시 자동 데이터 사용. 직접 입력은 동일 날짜 또는 더 오래된 자동값보다 우선합니다.

점수 산정 기준 및 주의사항

7개 지표를 0~100점으로 선형 환산하고 유효 가중치 합으로 나눕니다. 기회: RSI 70→30, 낙폭 0→-15%, 시장 폭 -5→+5%, VIX 15→40. 위험: RSI 65→25, 낙폭 0→-20%, 시장 폭 +5→-5%, VIX 15→40. MA20/50은 기존 기회·위험 점수에는 반영하지 않습니다. 추세전환 점수는 별도 산정합니다. SPY·QQQ 유효 데이터 및 50% 이상 커버리지가 필요합니다. 백테스트 미검증 모델입니다.

일봉은 실시간 시세가 아니며 배당/분할 조정 방식은 제공자별로 다릅니다. 고점은 최근 20거래일 고가 기준. 시장 폭은 동일가중 ETF 대비 시가총액가중 ETF의 20거래일 상대수익률로 실제 상승 종목 비중이 아닙니다. 7일 이상 오래된 가격은 점수에서 제외. 매매 신호나 투자 권유가 아닙니다.

API 키는 선택한 제공자에게 직접 전송됩니다. 별도 서버나 외부 라이브러리를 사용하지 않습니다. 파일 실행 환경에 따라 브라우저의 CORS 또는 저장소 제한이 있을 수 있습니다.
